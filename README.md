# Аннотация к воспроизведению решения

Для воспроизведения моего решения необходимо открыть файл с расширением `.ipynb` на Kaggle и загрузить необходимые датасеты, предоставляю ссылки на них:

1. https://www.kaggle.com/datasets/dattrinh12/icdar-2015
2. https://kaggle.com/datasets/prathmeshzade/iiit5k-words/versions/1
3. В явном виде сделать **upload** данного тестового датасета: я скачал предоставленный датасет в виде архива и добавил его при помощи upload.

Далее лучше всего выбрать **GPU** для обучения нейросети, иначе оно будет длиться довольно долго. 

Помимо этого в коде жестко прописан путь к тестовому датасету, который содержит **мой username Kaggle** (`balandinbogdan`). Перед запуском вам необходимо заменить его на **ваш личный username** (или на то имя папки, которое автоматически создалось при загрузке вашего архива через Upload).

Найдите в ноутбуке следующую строку:
